# Resi58

Aplikasi Android untuk mengubah PDF resi pengiriman (label A6 dari Shopee, TikTok Shop, Tokopedia, dan lainnya) menjadi potongan 58 mm yang siap dicetak di printer thermal — langsung dari HP, tanpa komputer.

## Unduh

**APK rilis (Android 8+):** [Unduh Resi58 v1.0.0](https://github.com/hardiviper/Resi58/releases/download/v1.0.0/Resi58.apk)

Belum tersedia di Play Store — dipasang manual (sideload). Izinkan "Install sumber tidak dikenal" saat diminta.

## Cara pakai

1. Pilih PDF resi
2. Geser garis merah untuk memotong (potongan bisa dibagi lagi atau dihapus)
3. Simpan, atau bagikan langsung ke aplikasi printer, WhatsApp, atau Telegram

## Persyaratan

- Android 8.0 (API 26) atau lebih baru
- Printer thermal 58 mm

## Tentang

Gratis dipakai. Tidak mengumpulkan data pribadi. Iklan (Start.io) ditampilkan untuk mendukung pengembangan. Kode sumber tidak dipublikasikan.
